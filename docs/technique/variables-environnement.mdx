# Variables d'Environnement et Configuration Technique SantéSN

> Répertoire exhaustif de toutes les variables d'environnement de la plateforme SantéSN : WhatsApp Cloud API Meta, Sentry DSN, Prometheus, Neon Postgres, Email SMTP/Brevo, Sécurité et Sessions.

SantéSN utilise des variables d'environnement pour séparer rigoureusement la configuration technique et les secrets cryptographiques du code source de l'application, en conformité avec les principes du manifeste *Twelve-Factor App*.

Ces variables sont injectées dynamiquement au démarrage par le gestionnaire d'environnement (fichier `.env` en local via `python-decouple`, panneau Vercel Environment Variables en Cloud, ou fichier `.env` monté dans Docker Compose).

<Warning>
  Ne commitez **jamais** de fichier contenant des valeurs réelles dans votre dépôt Git. Le fichier `.env` doit obligatoirement figurer dans `.gitignore`. Une fuite de clé secrète ou de chaîne de connexion compromettrait l'intégrité des données de santé.
</Warning>

---

## 1. Sécurité Principale & Django Core

<ParamField path="SECRET_KEY" type="string" required>
  Clé secrète Django fondamentale utilisée pour la signature cryptographique des cookies de session, des jetons CSRF et des signatures d'authentification.
  * Doit contenir au minimum 50 caractères aléatoires et complexes.
  * En production (`DEBUG=False`), le système refuse de démarrer si la clé par défaut est détectée.
  * **Exemple :** `django-insecure-santesn-2026-prod-4b791e8df1c3a628e932b109afcd95e8...`
</ParamField>

<ParamField path="DEBUG" type="boolean" default="False">
  Active ou désactive le mode de débogage de Django.
  * En développement : `True` (affiche les pages d'erreur détaillées).
  * En production : **`False` impératif** pour empêcher toute fuite d'informations système et de fragments de code.
</ParamField>

<ParamField path="ALLOWED_HOSTS" type="string" required>
  Liste des noms de domaine et adresses IP autorisés à traiter les requêtes HTTP arrivant sur l'application, séparés par des virgules.
  * **Exemple :** `localhost,127.0.0.1,projet-final-bice.vercel.app,santesn.sn,www.santesn.sn`
</ParamField>

<ParamField path="SITE_URL" type="string" default="https://projet-final-bice.vercel.app">
  URL canonique publique absolue de l'application, employée pour générer les liens absolus dans les notifications WhatsApp, les emails transactionnels et les QR Codes.
  * **Exemple :** `https://santesn.sn` ou `https://projet-final-bice.vercel.app`
</ParamField>

<ParamField path="DJANGO_ENV" type="string" default="production">
  Identifiant d'environnement transmis aux outils d'observabilité (notamment Sentry).
  * **Valeurs courantes :** `development`, `staging`, `production`.
</ParamField>

## 2. Base de Données Relationnelle (Neon PostgreSQL Cloud & Local)

SantéSN requiert une base de données PostgreSQL en production et supporte nativement les connexions SSL managées via **Neon Cloud Serverless**.

<ParamField path="DATABASE_URL" type="string">
  Chaîne de connexion universelle standard au serveur PostgreSQL. Si cette variable est définie, elle est prioritaire sur les variables individuelles `DB_*`.
  * **Format :** `postgresql://USER:PASSWORD@HOST:PORT/DBNAME?sslmode=require`
  * **Exemple Neon Cloud :** `postgresql://neondb_owner:npg_xxx@ep-round-tree-xxx.us-east-2.aws.neon.tech/santesn?sslmode=require`
  * Le moteur SantéSN gère automatiquement la réécriture du chemin Neon `/neondb` vers la base dédiée `/santesn`.
</ParamField>

<ParamField path="DB_ENGINE" type="string" default="postgresql">
  Moteur de base de données sélectionné en environnement sans URL directe.
  * Valeurs acceptées : `postgresql` (recommandé en production) ou `sqlite` (développement local rapide).
</ParamField>

<ParamField path="DB_NAME" type="string" default="santesn_db">
  Nom de la base de données PostgreSQL.
</ParamField>

<ParamField path="DB_USER" type="string" default="santesn_user">
  Nom d'utilisateur PostgreSQL propriétaire du schéma.
</ParamField>

<ParamField path="DB_PASSWORD" type="string">
  Mot de passe d'authentification pour l'utilisateur de base de données.
</ParamField>

<ParamField path="DB_HOST" type="string" default="localhost">
  Nom d'hôte ou adresse IP du serveur PostgreSQL (ex: `db` dans un réseau Docker Compose).
</ParamField>

<ParamField path="DB_PORT" type="integer" default="5432">
  Port d'écoute du serveur PostgreSQL (standard : `5432`).
</ParamField>

## 3. Scellement Cryptographique & Règles Métier Santé

<ParamField path="ORDONNANCE_SCEAU_CLE" type="string" required>
  Clé secrète cryptographique HMAC dédiée au scellement numérique des ordonnances médicales.
  * Garantit l'inviolabilité du QR Code imprimé ou affiché sur smartphone.
  * Tout changement de cette clé invalide la vérification des ordonnances antérieures.
  * **Exemple :** `cle-secrete-hmac-pour-signature-ordonnances-a-proteger-rigoureusement`
</ParamField>

<ParamField path="DELAI_VALIDITE_ORDONNANCE_JOURS" type="integer" default="90">
  Délai maximal de validité légale d'une ordonnance médicale pour délivrance en pharmacie (exprimé en jours). Au-delà, l'ordonnance est automatiquement déclarée expirée.
</ParamField>

<ParamField path="MAX_AYANTS_DROIT_PAR_ASSURE" type="integer" default="6">
  Plafond statutaire du nombre total de bénéficiaires dépendants rattachables à un même compte d'assuré principal.
</ParamField>

<ParamField path="MAX_CONJOINTS_PAR_ASSURE" type="integer" default="4">
  Nombre maximal de conjoints pouvant être rattachés légalement à un assuré principal (conforme au Code de la Famille du Sénégal).
</ParamField>

<ParamField path="MAX_ENFANTS_PAR_ASSURE" type="integer" default="6">
  Nombre maximal d'enfants à charge pouvant être déclarés comme ayants droit.
</ParamField>

## 4. Notifications WhatsApp Business (Meta Cloud API & Webhook)

SantéSN s'intègre directement avec l'API officielle **WhatsApp Cloud API** de Meta pour notifier les assurés lors de la création d'ordonnances, de la validation de remboursements ou de rappels de rendez-vous.

<ParamField path="WHATSAPP_ENABLED" type="boolean" default="False">
  Interrupteur d'activation de la passerelle WhatsApp.
  * `True` : Envoie les messages réels via les serveurs Meta Graph API.
  * `False` : Mode secours sans appel externe (bascule automatique sur notifications Email).
</ParamField>

<ParamField path="WHATSAPP_API_TOKEN" type="string">
  Jeton d'accès permanent délivré dans le portail Meta for Developers (`developers.facebook.com`) avec les permissions `whatsapp_business_messaging`.
  * **Format :** Préfixé généralement par `EAAX...`
</ParamField>

<ParamField path="WHATSAPP_PHONE_NUMBER_ID" type="string">
  Identifiant numérique unique du numéro de téléphone professionnel configuré dans le compte WhatsApp Business Cloud.
  * **Exemple :** `1372241212628957`
</ParamField>

<ParamField path="WHATSAPP_SENDER_PHONE" type="string" default="221789576145">
  Numéro de téléphone émetteur international affiché pour l'assistance et les messages de notification (format indicatif international sans `+`).
  * **Exemple :** `221789576145`
</ParamField>

<ParamField path="WHATSAPP_TEMPLATE_NAME" type="string" default="None">
  Nom du modèle de message structuré préalablement approuvé par Meta dans la console Business Manager (facultatif si utilisation de messages texte directs dans la fenêtre de 24h).
</ParamField>

<ParamField path="WHATSAPP_WEBHOOK_VERIFY_TOKEN" type="string" default="santesn_webhook_secret_2026">
  Jeton secret partagé utilisé lors de l'enregistrement du webhook SantéSN (`/whatsapp/webhook/`) dans le panneau développeur Meta pour valider l'authenticité de la souscription.
</ParamField>

<ParamField path="WHATSAPP_APP_SECRET" type="string">
  Clé secrète de l'application Meta employée pour vérifier la signature cryptographique HMAC-SHA256 (`X-Hub-Signature-256`) des notifications entrantes du bot WhatsApp.
</ParamField>

## 5. Observabilité, Télémétrie & Monitoring (Sentry & Prometheus)

<ParamField path="SENTRY_DSN" type="string">
  URL de capture d'événements Sentry (Data Source Name).
  * Lorsqu'elle est renseignée, le SDK Sentry initialise la capture des erreurs non interceptées et des traces de performance avec masquage automatique des données médicales sensibles.
  * **Exemple :** `https://62f051053735a37f44b9fbfabaaaf54c@o4512251337834496.ingest.de.sentry.io/4512251347468368`
</ParamField>

<ParamField path="PROMETHEUS_METRICS_TOKEN" type="string" default="santesn-prometheus-metrics-token-2026">
  Jeton d'autorisation Bearer secret exigé pour interroger l'endpoint machine `/metrics/`.
  * Tout collecteur Prometheus doit transmettre l'en-tête :
    `Authorization: Bearer <PROMETHEUS_METRICS_TOKEN>`
</ParamField>

## 6. Messagerie Transactionnelle (Email SMTP / Brevo / Gmail)

<ParamField path="EMAIL_BACKEND" type="string" default="django.core.mail.backends.smtp.EmailBackend">
  Backend de messagerie Django.
  * Production : `django.core.mail.backends.smtp.EmailBackend`
  * Tests automatisés : `django.core.mail.backends.locmem.EmailBackend`
  * Console locale : `django.core.mail.backends.console.EmailBackend`
</ParamField>

<ParamField path="EMAIL_HOST" type="string" default="smtp.gmail.com">
  Serveur SMTP de distribution des courriels transactionnels (ex: `smtp.brevo.com` ou `smtp.gmail.com`).
</ParamField>

<ParamField path="EMAIL_PORT" type="integer" default="587">
  Port SMTP de transmission (généralement `587` avec STARTTLS ou `465` avec SSL).
</ParamField>

<ParamField path="EMAIL_USE_TLS" type="boolean" default="True">
  Active le chiffrement TLS obligatoire pour sécuriser les flux SMTP.
</ParamField>

<ParamField path="EMAIL_HOST_USER" type="string">
  Identifiant de connexion au relais SMTP (adresse email ou clé API Brevo / Sendinblue).
</ParamField>

<ParamField path="EMAIL_HOST_PASSWORD" type="string">
  Mot de passe d'application SMTP ou clé secrète du service de messagerie.
</ParamField>

<ParamField path="DEFAULT_FROM_EMAIL" type="string" default="noreply@santesn.sn">
  Adresse d'expédition affichée aux destinataires lors de la réception des courriels.
</ParamField>

<ParamField path="SERVER_EMAIL" type="string" default="noreply@santesn.sn">
  Adresse utilisée par Django pour notifier les administrateurs en cas d'erreur serveur 500 critique.
</ParamField>

## 7. Sécurité HTTPS, Cookies & Durcissement Web

<ParamField path="SECURE_SSL_REDIRECT" type="boolean" default="True">
  Force la redirection automatique de toutes les requêtes HTTP non chiffrées vers HTTPS.
</ParamField>

<ParamField path="SESSION_COOKIE_SECURE" type="boolean" default="True">
  Interdit la transmission du cookie de session sur des liaisons HTTP non sécurisées (drapeau `Secure`).
</ParamField>

<ParamField path="CSRF_COOKIE_SECURE" type="boolean" default="True">
  Assure que le cookie CSRF n'est transmis que via une liaison chiffrée HTTPS.
</ParamField>

<ParamField path="CSRF_COOKIE_HTTPONLY" type="boolean" default="True">
  Empêche l'accès aux jetons CSRF par les scripts JavaScript côté client (défense contre attaques XSS).
</ParamField>

<ParamField path="CSRF_TRUSTED_ORIGINS" type="string">
  Liste des origines approuvées pour les requêtes POST/PUT soumises à la validation CSRF, séparées par des virgules.
  * **Exemple :** `https://projet-final-bice.vercel.app,https://santesn.sn,https://www.santesn.sn`
</ParamField>

<ParamField path="SECURE_HSTS_SECONDS" type="integer" default="31536000">
  Durée de rétention HSTS en secondes ordonnant aux navigateurs de ne communiquer qu'en HTTPS (31536000 secondes = 1 an).
</ParamField>

<ParamField path="SECURE_HSTS_INCLUDE_SUBDOMAINS" type="boolean" default="True">
  Étend la politique stricte HSTS à l'ensemble des sous-domaines (`*.santesn.sn`).
</ParamField>

<ParamField path="SECURE_HSTS_PRELOAD" type="boolean" default="True">
  Autorise l'inscription du domaine dans la liste de préchargement officiel HSTS des navigateurs (Chrome, Firefox, Safari).
</ParamField>

## 8. Conteneurs & Serveur Web (Docker / Gunicorn / Nginx)

<ParamField path="WEB_PORT" type="integer" default="80">
  Port d'écoute public exposé par le conteneur Nginx dans l'environnement Docker.
</ParamField>

<ParamField path="GUNICORN_WORKERS" type="integer" default="3">
  Nombre de processus workers Gunicorn concurrents exécutant l'application WSGI Django (règle recommandée : `2 * CPU_CORES + 1`).
</ParamField>

## Modèle de Fichier `.env.example`

Copiez ce modèle dans un fichier local nommé `.env` et adaptez les valeurs selon votre environnement :

```bash
# ==============================================================================
# Configuration Environnementale Complète — SantéSN
# ==============================================================================

# --- SÉCURITÉ DJANGO & CORE ---

DEBUG=False
ALLOWED_HOSTS=localhost,127.0.0.1,projet-final-bice.vercel.app,santesn.sn,www.santesn.sn
SITE_URL=https://projet-final-bice.vercel.app
DJANGO_ENV=production

# --- BASE DE DONNÉES CLOUD NEON POSTGRESQL ---
DATABASE_URL=postgresql://neondb_owner:votre_token@ep-xxx-pooler.c-5.us-east-2.aws.neon.tech/santesn?sslmode=require
DB_ENGINE=postgresql

# --- SCELLEMENT DES ORDONNANCES MÉDICALES (ANTI-FRAUDE) ---
ORDONNANCE_SCEAU_CLE=cle-secrete-hmac-pour-signature-ordonnances-a-proteger-rigoureusement
DELAI_VALIDITE_ORDONNANCE_JOURS=90

# --- QUOTAS FAMILLE & RÈGLES MÉTIER ---
MAX_AYANTS_DROIT_PAR_ASSURE=6
MAX_CONJOINTS_PAR_ASSURE=4
MAX_ENFANTS_PAR_ASSURE=6

# --- NOTIFICATIONS WHATSAPP CLOUD API (META) ---
WHATSAPP_ENABLED=True
WHATSAPP_API_TOKEN=EAAXGE8OjzPIBSob502MA...
WHATSAPP_PHONE_NUMBER_ID=1372241212628957
WHATSAPP_SENDER_PHONE=221789576145
WHATSAPP_WEBHOOK_VERIFY_TOKEN=santesn_webhook_secret_2026
WHATSAPP_APP_SECRET=votre_app_secret_meta

# --- MESSAGERIE TRANSACTIONNELLE (EMAIL SMTP / BREVO) ---

EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587

EMAIL_HOST_USER=votre-compte@santesn.sn
EMAIL_HOST_PASSWORD=votre-mot-de-passe-application
```
