# Routes et URLs disponibles sur la plateforme SantéSN

> Inventaire complet des routes publiques et protégées de SantéSN, avec méthodes HTTP, conditions d'accès et comportements de redirection.

SantéSN expose un ensemble de routes HTTP organisées selon le niveau d'accès requis. Les routes publiques sont accessibles sans authentification, tandis que les routes protégées exigent une session active — tout accès non authentifié déclenche une redirection automatique vers la page de connexion.

## Routes publiques

Ces routes sont accessibles à tous les visiteurs sans session active.

| Méthode | URL                           | Description                                         |
| ------- | ----------------------------- | --------------------------------------------------- |
| `GET`   | `/`                           | Page d'accueil publique de la plateforme            |
| `GET`   | `/connexion/`                 | Formulaire de connexion (email + mot de passe)      |
| `POST`  | `/connexion/`                 | Soumission des identifiants et démarrage de session |
| `GET`   | `/cgu/`                       | Conditions Générales d'Utilisation                  |
| `GET`   | `/politique-confidentialite/` | Politique de confidentialité et conformité CDP      |

## Routes protégées

Ces routes nécessitent une session authentifiée valide. Le contenu affiché varie automatiquement selon le rôle de l'utilisateur connecté (assuré, médecin, pharmacien, administrateur).

| Méthode | URL                 | Description                                       | Rôles autorisés             |
| ------- | ------------------- | ------------------------------------------------- | --------------------------- |
| `GET`   | `/tableau-de-bord/` | Tableau de bord personnalisé selon le rôle        | Tous les rôles              |
| `GET`   | `/ordonnances/`     | Liste des ordonnances accessibles à l'utilisateur | Assuré, Médecin, Pharmacien |

<Note>
  Tout accès à une route protégée sans session active entraîne une redirection immédiate vers `/connexion/`. Un message d'information signale l'expiration de session lorsque la durée de 8 heures est dépassée. L'URL d'origine est conservée en paramètre afin de rediriger l'utilisateur après reconnexion.
</Note>

## Interface d'administration

| Méthode | URL       | Description                                | Accès                       |
| ------- | --------- | ------------------------------------------ | --------------------------- |
| `GET`   | `/admin/` | Interface d'administration Django standard | Superutilisateur uniquement |

<Warning>
  L'interface `/admin/` est réservée aux superutilisateurs Django. En production, il est fortement recommandé de restreindre l'accès à cette URL par filtrage IP, reverse proxy, ou en modifiant le préfixe par défaut — laisser `/admin/` exposé publiquement sans protection supplémentaire constitue un risque de sécurité.
</Warning>

## Comportement de redirection

<Accordion title="Que se passe-t-il lorsqu'une session expire ?">
  Lorsque la session `sessionid` arrive à expiration (après 8 heures d'inactivité), le serveur invalide automatiquement le cookie de session côté serveur. Lors de la prochaine requête vers une route protégée, l'utilisateur est redirigé vers `/connexion/` avec un message l'informant que sa session a expiré. Il lui suffit de se reconnecter pour retrouver l'accès à la plateforme.
</Accordion>

<Accordion title="Les URLs sont-elles sensibles à la langue ?">
  Non. Toutes les URLs de SantéSN sont en français et constituent l'unique version disponible. Il n'existe pas de variante multilingue des routes à ce stade.
</Accordion>
