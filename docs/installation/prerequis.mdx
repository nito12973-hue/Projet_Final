# Prérequis pour installer SantéSN en développement local

> Vérifiez que Python 3.10+, pip, PostgreSQL et Git sont bien installés sur votre machine avant de cloner et configurer SantéSN en local.

Avant de cloner et de configurer SantéSN sur votre machine, assurez-vous que votre environnement dispose de tous les outils requis. Cette page liste l'ensemble des dépendances système, des logiciels et des compétences attendues pour démarrer sereinement.

## Logiciels requis

<CardGroup cols={2}>
  <Card title="Python 3.10+" icon="python" href="https://www.python.org/downloads/">
    SantéSN est développé avec Django, qui requiert Python 3.10 minimum. Nous recommandons la dernière version stable de Python 3.11 ou 3.12.
  </Card>

  <Card title="pip ou pipenv" icon="box" href="https://pip.pypa.io/en/stable/installation/">
    Gestionnaire de paquets Python pour installer les dépendances du projet. `pip` est inclus avec Python ; `pipenv` peut être installé séparément.
  </Card>

  <Card title="PostgreSQL" icon="database" href="https://www.postgresql.org/download/">
    SantéSN utilise PostgreSQL comme base de données relationnelle. Vous pouvez utiliser une instance locale ou un service cloud (ex. : Supabase, Neon, ElephantSQL).
  </Card>

  <Card title="Git" icon="code-branch" href="https://git-scm.com/downloads">
    Nécessaire pour cloner le dépôt du projet et gérer les branches de développement.
  </Card>

  <Card title="Vercel CLI" icon="cloud" href="https://vercel.com/docs/cli">
    Requis uniquement si vous souhaitez déployer l'application sur Vercel depuis votre terminal. Un compte Vercel gratuit suffit pour les environnements de prévisualisation.
  </Card>

  <Card title="VS Code (recommandé)" icon="laptop-code" href="https://code.visualstudio.com/">
    Éditeur de code recommandé. Les extensions Python, Django et dotenv facilitent le développement.
  </Card>
</CardGroup>

## Connaissances requises

<Info>
  SantéSN est une application Django standard. Une maîtrise des concepts fondamentaux de Django (modèles, vues, URLs, migrations, ORM) est indispensable pour contribuer au projet ou l'administrer localement.
</Info>

Une bonne connaissance des éléments suivants est attendue :

* **Django 4.x** — modèles, vues basées sur des classes, système de templates, migrations
* **Python 3.10+** — syntaxe moderne, environnements virtuels, gestion des dépendances
* **PostgreSQL** — création de bases de données, gestion des rôles et permissions
* **Variables d'environnement** — configuration via fichier `.env` et bibliothèque `python-decouple` ou `django-environ`
* **Ligne de commande** — exécution de commandes `manage.py`, navigation dans les répertoires

## Vérification des prérequis

Suivez ces étapes pour vous assurer que chaque outil est correctement installé sur votre machine avant de passer à la configuration.

<Steps>
  <Step title="Vérifier Python">
    Ouvrez un terminal et exécutez la commande suivante :

    ```bash theme={null}
    python --version
    ```

    ou, selon votre système :

    ```bash theme={null}
    python3 --version
    ```

    Vous devez obtenir une version **3.10 ou supérieure**, par exemple :

    ```
    Python 3.11.9
    ```

    <Warning>
      Si Python n'est pas installé ou si la version est inférieure à 3.10, téléchargez la dernière version stable sur [python.org](https://www.python.org/downloads/).
    </Warning>
  </Step>

  <Step title="Vérifier pip">
    Vérifiez que le gestionnaire de paquets `pip` est disponible :

    ```bash theme={null}
    pip --version
    ```

    Exemple de sortie attendue :

    ```
    pip 24.0 from /usr/local/lib/python3.11/site-packages/pip (python 3.11)
    ```

    <Tip>
      Si vous préférez utiliser `pipenv` pour isoler vos dépendances, installez-le avec `pip install pipenv`.
    </Tip>
  </Step>

  <Step title="Vérifier PostgreSQL">
    Contrôlez que le client PostgreSQL est installé et accessible :

    ```bash theme={null}
    psql --version
    ```

    Exemple de sortie attendue :

    ```
    psql (PostgreSQL) 15.6
    ```

    Pour vérifier que le service PostgreSQL est actif sur votre machine :

    ```bash theme={null}
    # Sur Linux / macOS avec systemd
    pg_isready

    # Sur macOS avec Homebrew
    brew services list | grep postgresql
    ```

    <Note>
      Si vous utilisez une base de données PostgreSQL hébergée dans le cloud (Supabase, Neon…), le client local `psql` n'est pas strictement obligatoire, mais il reste utile pour inspecter votre base de données.
    </Note>
  </Step>

  <Step title="Vérifier Git">
    Confirmez que Git est installé :

    ```bash theme={null}
    git --version
    ```

    Exemple de sortie attendue :

    ```
    git version 2.44.0
    ```

    Si Git n'est pas présent, téléchargez-le sur [git-scm.com](https://git-scm.com/downloads).
  </Step>

  <Step title="Vérifier la Vercel CLI (optionnel)">
    Si vous prévoyez de déployer sur Vercel depuis votre terminal, vérifiez que la CLI est installée :

    ```bash theme={null}
    vercel --version
    ```

    Exemple de sortie attendue :

    ```
    Vercel CLI 34.2.0
    ```

    Si la CLI n'est pas installée, vous pouvez l'ajouter via npm :

    ```bash theme={null}
    npm install -g vercel
    ```

    <Info>
      Le déploiement sur Vercel est également possible depuis l'interface web [vercel.com](https://vercel.com) sans passer par la CLI.
    </Info>
  </Step>

  <Step title="Vérifier VS Code (optionnel)">
    Si vous utilisez VS Code, vérifiez qu'il est accessible depuis le terminal :

    ```bash theme={null}
    code --version
    ```

    Exemple de sortie attendue :

    ```
    1.89.1
    ```

    Nous recommandons d'installer les extensions suivantes :

    * **Python** (Microsoft)
    * **Django** (Baptiste Darthenay)
    * **DotENV** (mikestead)
  </Step>
</Steps>
