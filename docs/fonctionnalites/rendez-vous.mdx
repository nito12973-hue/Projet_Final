# Prise de rendez-vous médicaux en ligne sur SantéSN

> Réservez une consultation sur SantéSN : choisissez prestataire, médecin, date et créneau. Suivez vos rendez-vous depuis votre tableau de bord.

La fonctionnalité de prise de rendez-vous de SantéSN vous permet, en tant qu'assuré, de réserver une consultation médicale directement depuis votre tableau de bord, sans appel téléphonique. Vous choisissez librement votre prestataire de soins, le médecin que vous souhaitez consulter, puis la date et le créneau qui vous conviennent parmi les disponibilités affichées en temps réel. Le médecin reçoit une notification automatique dès la confirmation de votre réservation.

<Info>
  Le flux de réservation détaillé ci-dessous est déduit du comportement observable de la plateforme. Les étapes de sélection du médecin, du créneau et la notification automatique n'ont pas été vérifiées dans le code source. ## Prendre un rendez-vous

<Steps>
  <Step title="Accédez à la section Rendez-vous">
    Depuis votre tableau de bord (`/tableau-de-bord/`), cliquez sur **Prendre un rendez-vous**. Vous accédez au formulaire de réservation guidé.
  </Step>

  <Step title="Choisissez un prestataire de soins">
    Sélectionnez l'établissement de santé (clinique, cabinet médical, centre de santé) dans lequel vous souhaitez être reçu. La liste affiche uniquement les prestataires partenaires de votre IPM ou compagnie d'assurance.
  </Step>

  <Step title="Choisissez un médecin">
    Parmi les médecins rattachés au prestataire sélectionné, choisissez le praticien que vous souhaitez consulter. Vous pouvez voir leur spécialité pour orienter votre choix.
  </Step>

  <Step title="Sélectionnez une date">
    Le calendrier affiche les jours disponibles pour le médecin choisi. Les jours sans disponibilité sont grisés. Cliquez sur la date souhaitée pour passer à l'étape suivante.
  </Step>

  <Step title="Choisissez un créneau horaire">
    Les créneaux horaires disponibles pour la date sélectionnée s'affichent. Sélectionnez celui qui vous convient. Les créneaux déjà réservés par d'autres patients ne sont pas proposés.
  </Step>

  <Step title="Confirmez le rendez-vous">
    Vérifiez le récapitulatif de votre réservation (prestataire, médecin, date, heure) puis cliquez sur **Confirmer le rendez-vous**. Le rendez-vous est immédiatement enregistré dans votre tableau de bord et une notification est envoyée au médecin.
  </Step>
</Steps>

<Tip>
  Confirmez votre rendez-vous le plus tôt possible. Les créneaux disponibles peuvent être pris rapidement, surtout chez les spécialistes très demandés. Si vous devez annuler, faites-le depuis votre tableau de bord le plus tôt possible afin de libérer le créneau pour un autre patient.
</Tip>

## Suivi de vos rendez-vous

Une fois réservé, votre rendez-vous apparaît dans la section **Mes rendez-vous** de votre tableau de bord. Chaque rendez-vous est associé à l'un des statuts suivants :

<CardGroup cols={2}>
  <Card title="À venir" icon="clock" href="https://projet-final-bice.vercel.app/tableau-de-bord/">
    Le rendez-vous est planifié. Vous pouvez encore l'annuler depuis votre tableau de bord.
  </Card>

  <Card title="Confirmé" icon="circle-check" href="https://projet-final-bice.vercel.app/tableau-de-bord/">
    Le médecin ou l'établissement a confirmé le rendez-vous. Présentez-vous à l'heure convenue.
  </Card>

  <Card title="Annulé" icon="circle-xmark" href="https://projet-final-bice.vercel.app/tableau-de-bord/">
    Le rendez-vous a été annulé, soit par vous, soit par le prestataire. Vous pouvez en reprendre un nouveau.
  </Card>

  <Card title="Terminé" icon="flag-checkered" href="/fonctionnalites/consultations">
    La consultation a eu lieu. Le rendez-vous est archivé dans votre historique et peut être associé à une ordonnance.
  </Card>
</CardGroup>

## Notification au médecin

Dès que vous confirmez votre réservation, le médecin concerné reçoit une notification automatique dans son agenda SantéSN. Il peut voir le nom de l'assuré, la date et l'heure du rendez-vous. De votre côté, aucune action supplémentaire n'est nécessaire : le rendez-vous est directement visible dans votre tableau de bord.

## Rendez-vous pour les ayants droit

Si vous gérez des dépendants (conjoint, enfants) rattachés à votre compte principal, vous pouvez également prendre des rendez-vous en leur nom. Lors de la réservation, sélectionnez le bénéficiaire concerné parmi vos ayants droit enregistrés.

<Note>
  La prise de rendez-vous est réservée aux assurés disposant d'un compte actif et d'une couverture en cours de validité. Si vous ne voyez pas certains prestataires ou médecins dans la liste, vérifiez auprès de votre administrateur que ces prestataires sont bien inclus dans votre plan de couverture.
</Note>
