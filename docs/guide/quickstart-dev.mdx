# Guide de démarrage rapide pour développeurs SantéSN

> Installez et lancez SantéSN en local en moins de 10 minutes : environnement virtuel, migrations, superutilisateur, tests et serveur de développement.

Ce guide s'adresse aux développeurs et contributeurs qui souhaitent installer SantéSN sur leur machine locale, explorer le code source et valider l'exécution des tests unitaires et d'intégration. À l'issue de ces étapes, vous disposerez d'une instance fonctionnelle avec un accès complet à l'interface d'administration Django et aux espaces par rôle.

## Prérequis

Avant de commencer, assurez-vous que votre poste dispose des éléments suivants :

## Installation pas à pas

<Steps>
  ### Cloner le dépôt

  Ouvrez un terminal et clonez le dépôt GitHub du projet dans le dossier de votre choix :

  ```bash
  git clone https://github.com/votre-organisation/Projet_Final.git
  cd Projet_Final
  ```

  ### Créer et activer un environnement virtuel

  Un environnement virtuel isole les dépendances du projet de votre installation Python globale. Créez-le à la racine du projet :

  ```bash
  python -m venv venv
  ```

  Activez-le selon votre système d'exploitation :

  <Tabs>
    <Tab title="Windows (PowerShell)">
      ```powershell
      venv\Scripts\Activate.ps1
      ```
    </Tab>

    <Tab title="Windows (cmd)">
      ```cmd
      venv\Scripts\activate.bat
      ```
    </Tab>

    <Tab title="macOS / Linux">
      ```bash
      source venv/bin/activate
      ```
    </Tab>
  </Tabs>

  Une fois activé, votre invite de commande affiche le préfixe `(venv)`.

  ### Installer les dépendances

  Installez toutes les bibliothèques Python requises en une seule commande :

  ```bash
  pip install -r requirements.txt
  ```

  ### Configurer le fichier d'environnement `.env`

  SantéSN utilise un fichier `.env` pour charger ses variables de configuration. Créez votre fichier `.env` à la racine :

  ```ini
  # Paramètres Django
  DJANGO_SECRET_KEY=cle_secrete_de_developpement_locale
  DEBUG=True
  ALLOWED_HOSTS=localhost,127.0.0.1

  # Base de données (SQLite en local par défaut ou PostgreSQL Neon)
  DATABASE_URL=sqlite:///db.sqlite3
  ```

  ### Appliquer les migrations de base de données

  Appliquez les migrations pour initialiser le schéma de données (modèles multi-tenants, ordonnances, conventions, journal) :

  ```bash
  python manage.py migrate
  ```

  ### Exécuter la suite de tests automatisés

  Vérifiez la conformité de l'installation en exécutant la suite de **946 tests automatisés** :

  ```bash
  python manage.py test Plateform_medicale
  ```

  La sortie doit afficher `OK` avec 0 échec et 0 erreur.

  ### Créer un compte administrateur

  Créez un compte superutilisateur pour accéder à la console d'administration et au tableau de bord technique :

  ```bash
  python manage.py createsuperuser
  ```

  ### Lancer le serveur de développement

  Démarrez le serveur Django intégré :

  ```bash
  python manage.py runserver
  ```

  L'application est immédiatement accessible à l'adresse [http://127.0.0.1:8000/](http://127.0.0.1:8000/).
</Steps>

## Créer des utilisateurs de test par rôle

Pour tester l'ensemble des parcours applicatifs de SantéSN, connectez-vous avec votre compte superutilisateur et provisionnez un utilisateur pour chaque rôle métier :

<CardGroup cols={2}>
  <Card title="Assuré" icon="user" href="/fonctionnalites/roles-permissions">
    Bénéficiaire affilié à un organisme. Peut prendre des rendez-vous, consulter ses ordonnances, déclarer ses ayants droit et suivre ses remboursements.
  </Card>

  <Card title="Médecin" icon="stethoscope" href="/fonctionnalites/consultations">
    Praticien de santé. Gère son agenda de consultations, prescrit des ordonnances sécurisées par QR Code et accède au dossier médical confidentiel.
  </Card>

  <Card title="Pharmacien" icon="pills" href="/fonctionnalites/ordonnances">
    Officine agréée. Scanne le QR Code des ordonnances, valide la dispensation et applique le verrou anti-double-délivrance.
  </Card>

  <Card title="Gestionnaire IPM" icon="building" href="/fonctionnalites/organismes-multi-tenant">
    Gestionnaire d'assurance/mutuelle. Administre les effectifs de son organisme, valide les prises en charge et gère les télétransmissions B2B.
  </Card>

  <Card title="Administrateur" icon="shield" href="/technique/supervision-observabilite">
    Superviseur global. Accède aux sondes de monitoring `/supervision/`, aux métriques `/metrics/` et au journal d'audit immuable.
  </Card>
</CardGroup>

## Commandes de gestion courantes

| Commande | Description |
| :--- | :--- |
| `python manage.py test Plateform_medicale` | Lance l'ensemble des 946 tests automatisés |
| `python manage.py migrate` | Applique les migrations déclaratives de l'ORM |
| `python manage.py createsuperuser` | Crée un compte superadministrateur |
| `python manage.py collectstatic` | Compile et rassemble les assets statiques (CSS/JS) |
| `python manage.py check` | Vérifie la cohérence du projet et des modèles |
